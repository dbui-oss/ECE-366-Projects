## How to Run the Program in MARS

1. Launch the program "FibIsOdd" after downloading it from GitHub using the provided repository link, then open it in MARS

2. In the .data section, you will notice an instruction in main that says "n:word 9", with the number 9 here being the test variable for the input (This input means the index  in Fibonacci series, so a number 9 means the 9th index, which translate to the number 34), feel free to change it to any number as you wish to test the program (The highest number you can put in is 46 though because of the 32 bit integer limit)

3. Assemble the program then run it 

4. To verify the result, go to the Data Segment table, find address 0x10010000 at Value(+4) which is where the result is stored. It will show 2 values, either 0 or 1, with 0 meaning the Fibonacci number is an even , and 1 meaning the fibonacci number is odd
